# Native iOS feature parity

Audit date: 2026-10-18. Scope: the 53 explicit incumbent mobile feature groups in the local functionality inventory. This is a source audit of the current working tree, including concurrent work; it is not a declaration that the replacement is complete or ready to install. Web-only features are excluded. Language scope: English only for now, per user; non-English app localization is excluded. Voice search is intentionally excluded by the user. Target: iPhone 15 Pro on iOS 27 only; iPad, earlier iOS versions and other form factors are not requirements. The share-extension row corrects an initial inventory overstatement using the actual incumbent consumer.

**Done** means the listed behavior has a concrete source implementation. **Partial** names an implemented flow and specific missing behavior. **Missing** means the incumbent feature has no equivalent implementation beyond a limited prerequisite. All rows still require relevant UI/device verification; a compiler pass is not a functional pass.

Source status: **53 done, 0 partial, 0 missing**. These are source-audit labels, not a completion percentage or runtime verification result. Collection-grid bulk actions are implemented for media categories and folders; other collection grids remain outside that coverage.
