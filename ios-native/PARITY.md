# Native iOS feature parity

Audit date: 2026-10-18. Scope: the 53 explicit incumbent mobile feature groups in the local functionality inventory. This is a source audit of the current working tree, including concurrent work; it is not a declaration that the replacement is complete or ready to install. Web-only features are excluded. Voice search is intentionally excluded by the user. Target: iPhone 15 Pro on iOS 27 only; iPad, earlier iOS versions and other form factors are not requirements. The share-extension row corrects an initial inventory overstatement using the actual incumbent consumer.

**Done** means the listed behavior has a concrete source implementation. **Partial** names an implemented flow and specific missing behavior. **Missing** means the incumbent feature has no equivalent implementation beyond a limited prerequisite. All rows still require relevant UI/device verification; a compiler pass is not a functional pass.

Source status: **46 done, 7 partial, 0 missing**. These are source-audit labels, not a completion percentage or runtime verification result. Collection-grid bulk actions are implemented for media categories and folders; other collection grids remain outside that coverage.

## Verification evidence

- Earlier source snapshots passed Swift 6 strict-concurrency typechecking against the Mac Catalyst SDK with real UIKit, PhotoKit, RealityKit and Google Cast headers, along with selected pure checks and XCTest suites. These results do not establish the current tree.
- Xcode 27 / iPhone 15 Pro on iOS 27 CI at `565e80b8e` compiled successfully: 66 unit tests and 9 of 12 UI tests passed. Select after closing Shelves/scrolling, Next memory hit testing, and the stale heading after a memory date jump failed. The current tree adds deferred grid-position publication, exact heading verification and temporary DEBUG hit-test diagnostics; release packaging remains gated on successful tests.
- The current memory-to-timeline navigation passes all 11 executable LibraryStore checks and Swift 6 strict-concurrency source typechecking against Mac Catalyst headers. Its new iOS UI test has not run yet; those checks do not replace simulator or device validation.
- Current UI tests cover sign-in and fixture-backed library interactions. PhotoKit permissions/cloud resources, true background upload, biometrics, Cast hardware, share/widgets and native visual fidelity have not been verified end to end.
- Reset-local-metadata, free-up-space candidate totals, and the haptic and timeline storage preferences are newly implemented in source and await current-tree Xcode tests; no iOS test pass is claimed for them.
- No deletion test has run on user photos. Cleanup uses durable backup receipts and fresh remote/local/account checks, and retains unverified/edited/auxiliary variants.
